## Task
The task is to complete a set of small Python functions using pandas. Each function performs a basic data manipulation operation such as loading data, selecting columns, filtering rows, handling missing values, grouping, and renaming.
The challenge is to correctly use pandas methods and indexing while matching the expected output format exactly.

## Description
Each exercise solves one specific pandas operation:
Loading CSV data from a StringIO object
Extracting column names from a DataFrame
Returning first N rows or columns
Selecting only numeric columns
Sampling random rows
Renaming a specific column
Detecting missing values
Dropping NaN values
Dropping a column
Grouping data by a column
Filtering rows based on a condition
Each function is implemented using the appropriate pandas method such as:
read_csv, head, iloc, select_dtypes, sample, rename, isnull, dropna, drop, groupby, and boolean indexing.

## Installation
No installation needed beyond pandas.

## Usage
Each function takes a pandas DataFrame (or CSV StringIO input in ex00) and returns a transformed version of it.


```
./my_project argument1 argument2
```
