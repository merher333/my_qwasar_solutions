# Welcome to Python Quest04
***

## Task
This project involved solving basic string manipulation tasks in Python:
- Finding the index of a character in a string.
- Converting a string to uppercase.
- Converting a string to lowercase.
- Calculating the length of a string.


## Description
1. `my_string_index`: Finds the first occurrence of a character in a string.
2. `my_upcase`: Converts a string to uppercase.
3. `my_downcase`: Converts a string to lowercase.
4. `my_size`: Calculates the length of a string.
