# Welcome to Quest04
***

## Task
Quest04 - A set of exercises to practice memory allocation, string manipulation, and pointer handling in C.

## Description
This project contains six exercises:
- **my_range.c**: Creates an array of integers between `min` and `max`.
- **my_strdup.c**: Duplicates a given string into a new memory location.
- **my_print_words_array.c**: Prints an array of strings, one per line.
- **my_count_on_it.c**: Counts the length of each string in an array.
- **my_join.c**: Joins an array of strings with a separator.
- **my_spaceship.c**: Simulates a spaceship's movement based on input commands.
Each file is written in C and demonstrates working with **dynamic memory allocation**, **structs**, and **string manipulation**.

## Installation
No special installation is required. Each file can be compiled with `gcc`:
```bash
gcc -Wall -Wextra -Werror ex00/my_range.c -o my_range
Repeat for each exercise.
## Usage
Each program runs independently. Example:
./my_range
Replace my_range with the compiled output name for other exercises.

```
./my_project argument1 argument2
```
