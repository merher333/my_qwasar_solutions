# Welcome to Python Quest01
***

## Task
 The project involves completing multiple small tasks to understand the basics of Python, such as creating variables, using conditional statements, and implementing basic operations.

## Description
Each exercise in this project required solving a specific problem using Python. The goal was to familiarize myself with Python syntax, logic, and workflow in programming.

## Installation
To run the scripts:
1. Clone the repository:
git clone <repository-link> cd project
2. Ensure Python 3 is installed on your system:
python3 --version

## Usage
Each task is organized into directories (`ex00`, `ex01`, etc.). Use the following commands to run specific tasks:
```bash
python3 <file_name>.py
Example:
python3 ex00/my_first_script.py

```
./my_project argument1 argument2
```
