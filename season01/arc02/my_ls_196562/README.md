# Welcome to My Ls
***

## Task
What is the problem? And where is the challenge?
The challenge was to create a program that mimics the execution of ls command and some of its flags.

## Description
How have you solved the problem?
I created my_ls function that parse arguments and then calls another function that displays directory content according to the flag or flags passed. I also wrote helper functions for sorting alphabetically and by time.

## Installation
How to install your project? npm install? make? make re?
make
make re

## Usage
How does it work?
```
./my_ls
./my_ls .
./my_ls -t
./my_ls -a
./my_ls -ta 
./my_ls -t -a 
./my_ls not_existing_dir
./my_ls existing_dir1 existing_dir2
```
