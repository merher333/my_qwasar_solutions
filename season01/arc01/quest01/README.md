# Welcome to My First C Programming Quest
***

## Task
The goal of this project is to learn the basics of the C programming language. This includes variables, loops, conditions, functions, and more. These exercises build a foundation for understanding memory management, system calls, and writing efficient programs.

## Description
This project contains 20 exercises designed to introduce essential C concepts. Each task focuses on a specific aspect of the language, progressing from simple compilation to functions and loops.

What we covered:
- Variables: Integers, characters, and strings.
- Loops: Using `while` and `for` to repeat actions.
- Conditions: Writing logical statements with `if` and `else`.
- Functions: Creating reusable code blocks.
- System Calls: Learning to use `write()` for output.

## Installation
To work with the project, simply clone the repository and ensure you have GCC installed. You can install it on Ubuntu with:
```bash
sudo apt update
sudo apt install gcc

## Usage
To run any specific exercise, navigate to its directory, compile the .c file, and run the resulting binary:
cd exXX
gcc -o program_name program_name.c
./program_name
Example:
cd ex00
gcc -o my_first_compilation my_first_compilation.c
./my_first_compilation
