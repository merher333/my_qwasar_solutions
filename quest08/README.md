# Welcome to Quest08
## Task
The goal of Quest08 is to master basic string manipulation in C by building three different functions without relying on standard string functions. Each task involves a unique string processing challenge that must be solved using loops and memory allocation.
## Description
hidenp: Checks if the characters from the first string appear in order inside the second string.
my_split: Splits a string by a single-character separator and returns an array of non-empty substrings using the string_array struct.
my_strip: Returns a clean version of the string with no leading or trailing whitespace and exactly one space between words.
All logic is written using basic loops and malloc, without functions like strtok or strcpy.
## Installation
No installation needed. Just compile using gcc:
gcc -Wall -Wextra -Werror -o test test.c your_function.c
## Usage
Each file is a separate function. You can write a simple `main()` to test it.
./test

```
./my_project argument1 argument2
```
