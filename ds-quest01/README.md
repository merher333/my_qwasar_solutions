## Task
The goal of this project is to explore the basics of the NumPy library in Python.
The challenge is to understand how to create, manipulate, and perform operations on arrays using NumPy instead of standard Python lists.

## Description
The problem was solved by using built-in NumPy functions to handle arrays efficiently.
Each exercise focuses on a specific feature, such as creating arrays, filling them with values, sorting, and performing mathematical operations.
The implementation relies on simple and direct use of NumPy methods like array(), zeros(), arange(), add(), and sum(). I've learned how to use NumPy on DataCamp.

## Installation
Make sure Python is installed, then install NumPy:
pip install NumPy

## Usage
Each function can be called with the required parameters to perform a specific operation.

Example:
import numpy as np

from my_numpy_journey_one_d_array import my_numpy_journey_one_d_array

result = my_numpy_journey_one_d_array([1, 2, 3, 4])
print(result)

Each file contains a function that demonstrates a specific NumPy feature, and they can be tested individually.


```
./my_project argument1 argument2
```
