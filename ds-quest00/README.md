# Welcome to Ds Quest00
***

## Task
The challenge was to create and submit Jupyter Notebook (.ipynb) files inside the Qwasar DoCode environment, which does not provide a built-in Jupyter interface.
The main difficulty was understanding how to properly create and handle notebook files without direct support in the platform.

## Description
The problem was solved by creating the notebooks outside of DoCode using Jupyter.
I used a Jupyter environment (browser-based), created the required notebooks there, and ensured they followed the exact naming and structure required by the subject.
After that:
I downloaded the .ipynb files
Uploaded them into the correct directories (ex00, ex01, ex02) inside DoCode
Committed and pushed them to the repository.
This approach worked successfully and all exercises passed on the first attempt.

## Installation
Use any Jupyter environment (local Jupyter Notebook or browser-based)
Create .ipynb files
Download them
Upload them into the DoCode project directories

## Usage
Each notebook contains simple Python code executed inside Jupyter cells:
ex00: Empty notebook (structure only)
ex01: Prints "Hello world!"
ex02: Contains three separate cells printing:
Cell1
Cell2
Cell3
The notebooks are not executed inside DoCode but are validated based on their structure and content.


```
./my_project argument1 argument2
```
