# Welcome to Python Quest02
***

## Task
The project involves practicing Python basics by completing various small tasks:
- Using conditional statements with multiple conditions.
- Creating and calling functions.
- Using `while` loops for repetitive tasks.
- Passing parameters to functions.
- Using functions that return values.

## Description
The purpose of this project is to improve understanding of Python syntax and logic by solving specific problems in an organized way. Each task is an individual learning step.

## Installation
