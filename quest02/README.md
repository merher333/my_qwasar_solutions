# Welcome to Quest02 My Pointers Project
***

## Task
This project focuses on pointers, string manipulation, and basic arithmetic operations in C.  
Each exercise is designed to build a strong understanding of memory addresses, loops, and functions.


## Description
The following functions were implemented step by step:
- `my_initializer` → Sets an integer value to `0` using a pointer.
- `my_swap` → Swaps the values of two integers using pointers.
- `my_strlen` → Computes the length of a string.
- `my_putstr` → Displays a string character by character.
- `my_add` → Adds two integers and returns the result.
- `my_sub` → Subtracts two integers and returns the result.
- `my_mult` → Multiplies two integers and returns the result.
- `my_string_formatting` → Prints a formatted sentence with a first name, last name, and age.
- `my_string_index` → Finds the first occurrence of a character in a string.
- `my_upcase` → Converts a string to uppercase.
- `my_downcase` → Converts a string to lowercase.


## Installation

```bash
gcc -Wall -Wextra -o my_program my_program.c

## Usage
Each function can be tested individually by writing a main() function and compiling it.

Example:
#include <stdio.h>

int my_add(int param_1, int param_2);

int main() {
    printf("Sum: %d\n", my_add(10, 5)); // Output: 15
    return 0;
}
