# Welcome to Python Quest05
***

## Task
This project involves working with arrays and implementing various operations such as iteration, transformation, and checking properties.

## Description
Each task focuses on a different operation:

ex00 (My Each): Iterates through an array and prints each element.
ex01 (My Map Mult Two): Multiplies each integer in an array by 2 and returns the result.
ex02 (My Count On It): Returns an array of string lengths for each element in a string array.
ex03 (My Array Uniq): Removes duplicates from an array of integers.
ex04 (My Is Sort): Checks whether an array of integers is sorted in ascending or descending order.

## Installation
1. Clone the repository:
git clone <repo_url>  
cd project  
2.Ensure Python 3 is installed:
python3 --version  

## Usage
Run each script using Python 3:
python3 ex00/my_each.py  
python3 ex01/my_map_mult_two.py  
python3 ex02/my_count_on_it.py  
python3 ex03/my_array_uniq.py  
python3 ex04/my_is_sort.py  

```
./my_project argument1 argument2
```
