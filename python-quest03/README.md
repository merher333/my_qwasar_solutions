# Welcome to Python Quest03
***

## Task
This project involved solving several exercises to strengthen Python basics, including:
- Handling script arguments.
- Implementing conditional statements.
- Writing custom functions (addition, subtraction, multiplication, etc.).
- Formatting strings.

## Description
Each task builds on core Python skills:
1. **Script Arguments**: Print script arguments passed via the command line.
2. **Conditionals**: Identify positive and negative numbers.
3. **Custom Functions**: Implement addition, subtraction, multiplication, and absolute value functions.
4. **String Formatting**: Create formatted strings with input values.
