# Welcome to My Christmas Tree
***

## Task
Write a program that displays a Christmas tree in the terminal.  
The tree must be built using `*` characters, with each section growing in size.  
The size is passed as the first parameter to the program.
## Description
The program calculates the number of lines and stars needed for each section of the tree.  
It prints each line with the correct amount of leading spaces and stars to center the tree.  
After all blocks are drawn, it prints a centered trunk using `|` characters.  
Trunk width and height are equal to the given size.  
The spacing and shrinking between blocks was adjusted to match Gandalf's exact expectations.
## Installation
No installation needed. Just compile with `gcc`:
gcc -o my_christmas_tree my_christmas_tree.c
## Usage
./my_christmas_tree <size>
./my_christmas_tree 5
This will print a Christmas tree with 5 blocks and a 5-line trunk.

```
./my_project argument1 argument2
```
