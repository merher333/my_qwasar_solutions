# Welcome to My Roman Numerals Converter
***

## Task
- Write a Python function to convert numbers into Roman numerals.
- It supports numbers up to 3000 and handles special cases like IV and IX.

## Description
- The function uses a list of tuples to map values to Roman symbols.
- It subtracts values and appends Roman letters until the number becomes zero.
- Example: 1990 becomes "MCMXC".

## Installation
1. Clone the repository:
   ```bash
   git clone <repository_url>
2. Navigate into the project folder:
 `cd my_roman_numerals_converter`
3. Make sure Python 3 is installed on your system.

## Usage
To run the Roman numeral converter:
1. Open a terminal and navigate to the project directory:
   ```bash
   cd my_roman_numerals_converter
2. Run the script with Python 3, passing the desired number as an argument:
python3 ex00/my_roman_numerals_converter.py
3. Example usage:
python3 ex00/my_roman_numerals_converter.py 1990
This will output the Roman numeral equivalent:
- MCMXC.
```
