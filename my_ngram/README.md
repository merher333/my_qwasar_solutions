# Welcome to My Ngram
***

## Task
This program counts the occurrences of each character in a given text input. You can provide one or multiple text inputs, and it will output each character's frequency, sorted in alphanumeric order.

## Description
To solve this problem:
The program loops through each character in the given input(s).
It ignores double quotes (") to prevent formatting issues.
It stores occurrences in an ASCII-based array for efficiency.
Finally, it prints the character count in sorted order.
The output follows the format:
character:count
This allows for easy readability and further text processing.

## Installation
To compile the project, simply run:
make
This will generate an executable called my_ngram.

## Usage
Run the program with one or more text inputs:
./my_ngram "abcdef"
Output:
makefile
a:1
b:1
c:1
d:1
e:1
f:1
For multiple inputs:
./my_ngram "aaabb" "abc"
Output:
makefile
a:4
b:3
c:1
